# Sylor — Downloads

Public download mirror for **Sylor**, a calm, capable desktop coding assistant.

Sylor is **closed-source** — its source code is private. This repository exists only to host the installers so anyone can download them without a GitHub account. No source code is published here or anywhere else.

## Get Sylor

- **Windows:** [Sylor-Setup.exe](https://github.com/explorearafat/sylor-dist/releases/latest/download/Sylor-Setup.exe)
- **Android:** [sylor.apk](https://github.com/explorearafat/sylor-dist/releases/latest/download/sylor.apk)

Or open the download page: **[sylorcode.vercel.app/download](https://sylorcode.vercel.app/download)**

Try it in your browser first: **[sylorcode.vercel.app](https://sylorcode.vercel.app)**

---

The Windows installer and the Android APK are self-signed, so your OS will ask you to confirm the install the first time.
